# Ausvac Mining – WordPress build sources

Sources for the inner pages of https://ausvac-mining.wsdfy.com (Company, Services,
Publications, Contact), converted from the client design package.

- `wp-pages/` – page markup, page CSS/JS and assets deployed to the `ausvac-child` theme
  and the WordPress media library.
- `wp-pages/pages/*.json` – page definitions (title, slug, Elementor data) generated from the design.
- `wp-pages/theme/` – files deployed to the `ausvac-child` theme.
- `wp-pages/tools/` – scripts used to render the design pages and extract the markup.
